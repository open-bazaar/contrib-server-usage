# bazaar-contrib-server-usage

The usage at the top of a Bazaar Compute server's overview: how many agents are at work, how many new conversations wait to be let in and how many computers are offline, the agents running and those at work, and the turns and tokens of today, the last 7 days or the last 30, the turns against as many days before.

```toml
[[contribs]]
package = "bazaar-contrib-server-usage~=0.3.0rc1"
[[contribs.enabled]]
entry = "server-usage"
```
